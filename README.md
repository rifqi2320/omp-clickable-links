# omp-clickable-links

A dependency-free omp extension that enables omp's existing terminal hyperlinks. Your terminal opens links, normally with Command-click or Ctrl-click; the exact gesture depends on the terminal. No URL is passed to a shell, external program, or network service by this plugin.

## Install

Review the two source files, then link a local copy:

```sh
omp plugin link /path/to/omp-clickable-links
```

Restart omp. The plugin sets `tui.hyperlinks` to `always` only when you have not configured it yourself. Explicit settings, including `off`, take precedence. Uninstall with `omp plugin uninstall omp-clickable-links`.

## Limitations

This enables omp's OSC 8 hyperlinks; it cannot add hyperlink support to your terminal or force a browser to open. Your terminal and any multiplexer (such as tmux) must support OSC 8. Mouse capture, terminal preferences, SSH and multiplexers may affect the click gesture. Links generated by applications other than omp are unaffected. This extension does not handle `http` clicks itself: omp reserves web schemes for the terminal. Treat link destinations as untrusted and inspect them before opening.

Requires an omp version exposing `@oh-my-pi/pi-coding-agent/config/registry` and `tui.hyperlinks` (tested with omp 18.22.2). Extensions run in-process and are not sandboxed; review source before installing any plugin.
